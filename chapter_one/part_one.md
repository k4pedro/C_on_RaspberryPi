# Chapter One - Getting Started

    #include <stdio.h>
    void main (void)
    {
        printf("Hello World in terminal!\n");
    }

## Compile your program

1. Command for make a .exe into a file called **myprog**.
   > gcc –o myprog **hello_world.c**
2. Run **myprog** with a command line:
   > ./myprog
3. print in terminal
   > Hello World in terminal!
