# WIRINGPI como rodar no RaspBerry?

1. Instalar o Git no Rasp no direretorio **tmp**
    > cd /tmp
    >
    > sudo apt update
    >
    > apt install -y git
    
2. Clone o repositorio no github
    >
    >git clone https://github.com/WiringPi/WiringPi.git
    >
    >cd WiringPi
    >
    >./build

3. Volte ao diretorio do programa **cd SEU-DIR**
